## Как пользоваться
1. Положи оригинал в `input/`.
2. `python3 scripts/doctor.py` (только проверка).
3. В Claude Code: `/openall-start` → `/openall-spec` → `/openall-build` → `/openall-verify`.
   Цикл повторяй 3-5 раз.

Запускай чужие exe/apk только в песочнице или виртуальной машине.
