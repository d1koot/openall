# Disclaimer / Responsible use

**This is not legal advice.** If you plan anything serious, talk to a lawyer in your jurisdiction.

## What OpenAll is
A set of instructions, agents and helper scripts for Claude Code that help you **re-create the
behaviour and look of an application as brand-new code** (a "clean-room" style workflow):
one role observes and writes a specification, another role writes new code from that
specification only, a third role compares the result.

## What OpenAll is NOT
- It is **not** a tool for stealing source code, secrets, tokens, keys or user data.
- It is **not** a tool for bypassing licence checks, DRM, copy protection, anti-tamper or paywalls.
- It does **not** copy code, names, texts, logos, icons, fonts or other assets of the original.
- It does **not** guarantee that the result is legally safe to publish or sell.

## Intended use
- Your own applications (lost sources, re-platforming, rewrite in another stack).
- Open-source applications, respecting their licences.
- Interoperability and learning, where the law of your country allows it.
- Applications whose owner has given you permission.
